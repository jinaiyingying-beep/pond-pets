# Changelog

## v1.0.0 — 2026-10

First public release.

- Full-screen Mac desktop pond wallpaper (Swift shell + single-file Canvas pond in a WKWebView)
- Menu-bar control: feed, tap glass, add fish, pause, time-of-day and weather controls
- Ambient sound synthesized live with Web Audio (stream, rain, frogs, insects) — no audio files
- Fish persist locally (count, fullness, interactions) via localStorage
- Piranha school edition: 16 large red-bellied piranhas by default (up to 20), schooling formation and feeding-frenzy behaviour
